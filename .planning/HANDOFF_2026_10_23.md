## Corrections made (read this before quoting anything)

1. **QB anchor gain −0.079 → −0.035.** The first estimate simulated a
   point-blend; production does a *rank*-blend with minimal reassignment.
2. **TE anchor 0.5 → 0.75 "−0.18 MAE" → REJECTED.** That sweep point-blended
   on top of boards already carrying the rank-blend at 0.5. Measured properly
   through the CLI, the shipped 0.5 is already optimal (4.75 vs 4.80 vs 4.99).
3. **"WR/TE residual falls back to the heuristic" → WR only, and a 40%
   dilution**, not a fallback. The primary was always healthy; the secondary
   model's meta JSON was never committed.
4. **"Anchor coverage erosion 93% → 79%" → NOT A DEFECT.** Sleeper's slate
   shrinks seasonally (401 → 337 rows); startable coverage held at ~99%, and
   every unmatched startable was verified *absent from Sleeper's feed*.
5. **"No 2026 team-side Silver exists" was partly my own shallow search** —
   the data nests under `teams/`. It genuinely didn't exist locally, but the
   inventory table I produced was unreliable.

The common thread: the aggregate looked plausible, so nobody opened it up.

## Traps worth knowing

- **A merge to main does not change what a peer session generates.** After
  #134 merged, the waiver session wrote three *pre-lever* week-7 boards into
  the serving path from its pre-merge branch. Grading and prod both read the
  *latest* file in a partition, so the calibration was effectively undone
  until the board was regenerated from main. Check lever flags
  (`sleeper_anchor_flag` on QB rows, `dispersion_shrink_flag`,
  `band_calibration_flag`); don't assume.
- **`NaN > x` is `False` in pandas, not `NaN`.** Comparisons don't propagate
  missingness, which is how 179 unplayed games became wins.
- **Drive the production code path.** Twice, replaying a lever with a
  plausible stand-in gave a confidently wrong answer. Import the real
  function or run its CLI.
- **Assert non-vacuity.** Three new tests initially passed because their
  fixtures were below a lever's minimum row count, so it never ran.
- **`--help` breaks on a bare `%`** in argparse help text.
- **A `tail` in a pipeline eats the exit code.** A chain script reported
  `exit=0` for a step that had failed with a usage error.
- **`tests/test_bronze_2025.py` guards on a directory, not its contents**
  (`_FULL_LAKE_PRESENT = os.path.isdir(BRONZE_DIR/"pbp")`). An *empty*
  `data/bronze/pbp/` — which a partial ingest, or moving a season aside,
  easily leaves — flips 11 tests from skipped to run, and 5 then fail
  confusingly on absent 2025 data. Not fixed (test-only, local-run only), but
  if you see those five fail, check for an empty pbp directory before
  believing them.
- **Bronze PBP is untracked**, so a fresh worktree has none. Copy
  `data/bronze/pbp/season=YYYY` in if you need the ML or prediction paths, and
  remember to remove the directory (not just its contents) afterwards.
